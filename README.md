# 오늘 일본어

[학습 화면 열기](https://ngryun.github.io/ebs-japanese-study/)

최근 30회 일본어 방송의 녹음, 한국어 요약, 주요 단어와 원문 문장을 함께 보여주는 개인 학습 화면입니다.
분석이 완료되지 않은 회차는 녹음만 표시합니다. 모든 배포 자료는 인터넷에서 공개적으로 접근할 수 있습니다.

배포 도구는 맥의 최근 30회분을 `study-data` 릴리스에 배포 파일로 업로드합니다.
월요일~토요일 오전 5시 녹음과 학습 분석이 끝나면 자동으로 갱신합니다. 일요일에는 새 녹음이 없습니다.
GitHub Actions가 해당 파일을 받아 GitHub Pages에 배포합니다.
성공적으로 배포한 뒤 이전 배포 파일을 삭제하며 오디오를 Git 커밋 이력에 저장하지 않습니다.

설정, 로컬 서버 토큰, 전사 원본, 모델과 로그는 배포 자료에 포함하지 않습니다.
이 저장소는 배포 워크플로와 로컬 녹음·분석·학습 화면의 소스 코드를 보관합니다.

## 로컬 녹음과 학습 자료 생성

`scripts/`에는 녹음, Whisper 전사, Ollama 요약·번역, 학습 화면 생성과 Pages
업로드 도구가 있습니다. 자동 분석 모델은 **Qwen3.5-27B**이며, 원문을 대조하고
한국어 번역을 작은 묶음으로 교정합니다. 읽기와 품사는 Sudachi 사전으로 확인합니다.

설정은 `analysis.env.example`, `podcast.env.example`, `study_pages.example.json`을
복사해 지정합니다. 실제 설정 파일은 Git에서 제외합니다. 녹음, 분석 결과와 모델은
로컬에 보관합니다. 경로와 launchd 템플릿은 자신의 환경에 맞게 수정해야 합니다.

- [로컬 설정 및 실행 방법](docs/local-study.md)
- [Qwen3.5-27B / Qwen3.6-27B 비교 결과](docs/model-comparison-20261003.json)

동일한 12문장과 방송 전사로 비교한 소규모 시험에서 번역 검토 점수는
3.5-27B 66/72, 3.6-27B 63/72였습니다. 3.6의 최종 요약에도 문화명 표기 오류가
남아 현재 모델을 유지합니다. 이 점수는 AI의 원문 검토 결과이며 일반적인 모델
성능의 우열을 뜻하지 않습니다.

검증:

```sh
python3 -m unittest discover -s tests -v
```

현재 Pages 워크플로는 릴리스에 업로드한 배포 파일을 지정해 실행합니다.
소스 코드 커밋만으로 사이트가 재배포되지는 않습니다.
